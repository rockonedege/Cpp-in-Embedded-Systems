# Chapter 3: Embedded C++ Ecosystem

Standalone examples of memory errors and unit testing. You can explore them in
[Compiler Explorer](https://godbolt.org/).

The folder contains following examples:
- `out_of_bound.cpp` — out-of-bounds array access
- `uninitialized_value.cpp` — reading an uninitialized variable
- `google_test_example.cpp` — a unit test with GoogleTest (in Compiler
  Explorer, add gtest under Libraries)
