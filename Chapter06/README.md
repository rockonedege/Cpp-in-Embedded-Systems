# Chapter 6: Beyond Classes – Fundamental C++ Concepts

Standalone examples covering references, value categories, and standard
library algorithms and adaptors. You can explore them in
[Compiler Explorer](https://godbolt.org/).

The folder contains following examples:
- `function_overloading.cpp` — function overloading and overload resolution
- `lvalue_refs.cpp` — lvalue references
- `rvalue.cpp` — rvalues
- `rvalue_refs.cpp` — rvalue references and `std::move`
- `copy_if.cpp` — the `std::copy_if` algorithm
- `sort.cpp` — the `std::sort` algorithm
- `priority_queue_adaptor.cpp` — the `std::priority_queue` container adaptor
